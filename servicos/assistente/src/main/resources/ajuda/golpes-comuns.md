# Golpes comuns

## Falso parente
Alguém manda mensagem dizendo ser um parente com número novo e pede um Pix com urgência. Ligue para o número antigo da pessoa antes de pagar.

## Falsa central
O Ledgerly Bank nunca liga pedindo senha, código de verificação ou que você faça um Pix para "proteger" o seu dinheiro. Se alguém pedir, desligue.

## Por que o banco segura alguns Pix
Pix alto para uma conta aberta há poucos dias, que você nunca pagou, é o caminho mais comum do dinheiro de golpe. Por isso a análise de segurança costuma segurar esse tipo de Pix para uma pessoa conferir.
